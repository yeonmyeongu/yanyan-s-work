# 燕鸣宇建筑作品集

这是燕鸣宇的建筑与室内设计作品集网站。仓库根目录包含可直接由 GitHub Pages 发布的静态页面、样式、交互脚本和经 WebP 编码的项目效果图。

网站地址：[https://yeonmyeongu.github.io/yanyan-s-work/](https://yeonmyeongu.github.io/yanyan-s-work/)

页面中的项目图像为设计效果表达，非建成实景摄影。原始效果图文件未上传到此仓库。


图片画质：图集大图最高宽 3840 像素（不放大原图）、WebP 质量 94；封面最高宽 2400 像素、质量 94；缩略图宽 640 像素、质量 88。
